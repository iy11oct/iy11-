# 小y图纸作坊

> 正式版 1.0：把图片转换为可在手机、平板上查看的拼豆图纸。

小y图纸作坊是一个浏览器端的图片转拼豆图纸工具。上传图片、裁剪取景、选择图纸尺寸后，即可生成拼豆格子图、颜色用量清单，并将图纸保存到相册或本地设备。

图片处理和图纸生成主要在浏览器本地完成，不需要上传用户图片到服务器，适合个人创作、门店打样和拼豆爱好者使用。

## 功能

- 上传 PNG、JPG 等常见图片格式
- 裁剪时可拖动图片、缩放图片和旋转图片，方便保留主体或角落内容
- 支持 29 x 29、58 x 58、87 x 87、116 x 116 等常用图纸尺寸，也可以输入自定义宽高
- 使用 MARD 221 色拼豆色板进行颜色匹配
- 生成更适合实际制作的像素格图，支持合并孤立杂色
- 可选“白色背景不标注 H2”，减少不需要拼的背景色统计
- 点击格子可直接改色，支持吸取已有颜色和撤销修改
- 图纸区域支持鼠标滚轮缩放、中键拖动，以及手机和平板双指缩放
- 支持保存普通图纸、带色号图纸和颜色清单 PNG 图片，方便保存到相册
- 保存最近制作记录，方便继续调整此前的图纸

## 快速使用

1. 打开网站，点击“上传图片”。
2. 在裁剪界面拖动、缩放或旋转图片，完成取景。
3. 选择图纸尺寸、色板和图纸约束条件。
4. 点击“生成图纸”。
5. 在中间图纸区域缩放、拖动或点击格子微调颜色。
6. 点击“保存图纸”“保存带色号图纸”或“保存颜色清单图片”。

## 本地运行

### 环境要求

- Node.js 22.13 或更高版本
- npm

### 安装与启动

```bash
git clone https://github.com/iy11oct/iy11-.git
cd iy11-
npm install
npm run dev
```

启动后，在浏览器打开终端显示的本地地址即可使用。

### 常用命令

```bash
# 本地开发
npm run dev

# 生产构建
npm run build

# 运行生产构建
npm run start

# 代码检查
npm run lint
```

## 部署到腾讯云 CloudBase 静态网站托管

项目已启用静态导出，执行构建后，适合上传的静态文件位于 `dist/client`。

```bash
npm install
npm run build
```

随后在 CloudBase 控制台的“静态网站托管”中创建本地项目部署：

- 项目框架：`其他`
- 安装命令：留空
- 构建命令：留空
- 构建产物目录：`./`
- 部署路径：`/`

将 `dist/client` 内的文件直接上传，或者上传一个第一层就包含 `index.html` 的 ZIP 压缩包。不要把 `dist` 的上一层目录一起套进压缩包，否则默认域名会找不到首页并返回 `404 NoSuchKey`。

CloudBase 的默认域名适合测试。面向正式用户发布时，建议绑定自己的域名；如需中国大陆节点的稳定公开访问，请按腾讯云要求完成域名实名认证和 ICP 备案。
